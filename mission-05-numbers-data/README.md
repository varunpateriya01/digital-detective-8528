## 5. My understanding
Binary uses powers of 2, while hexadecimal uses powers of 16. Hexadecimal is compact because one hex digit represents four bits. Python can verify arithmetic, but showing place values or division remainders explains how the answer was reached. Text also becomes numbers in storage; an encoding standard tells software how to interpret those numbers as characters. ASCII covers a small basic set, while UTF-8 can represent a much wider range.
