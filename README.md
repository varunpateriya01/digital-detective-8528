## Topics explored

- How input, processing, output and storage work together.
- Hardware, software, operating systems, processes, paths and permissions.
- Terminal file operations, flags, pipes and package managers.
- Python program execution, compilers and interpreters.
- Decimal, binary and hexadecimal conversion, plus character encoding.
- Git commits, branches and Pull Requests.
- LAN, MAN, WAN, DNS, routers, protocols, packet switching and client-server communication.

## Run the number converter

From the repository root, run:

```sh
python3 mission-05-numbers-data/number_converter.py
```

Enter a non-negative decimal integer. The program prints its binary and hexadecimal forms.

## My Learning

The missions showed me that a computer combines hardware and software: the operating system manages the hardware while applications run as processes. Terminal and Git give me ways to manage files and record changes. Number bases and character encodings explain how data is represented, while DNS and network protocols explain how a browser reaches a website.
